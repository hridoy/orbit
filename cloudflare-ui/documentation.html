Cloudflare Kumo Admin Template

← Launch Live Dashboard

Premium commercial admin template mirroring Cloudflare's complete dashboard design system (Kumo). Built with 100% native HTML5, CSS3, and Vanilla JavaScript with zero external frameworks or heavy build dependencies.

Key Template Highlights

  • 29+ Complete Screens: Account Home, Zones Overview, DNS Records, WAF, SSL/TLS, Caching, Rules, Network, Workers & Pages, Worker Service Detail, D1 SQLite Databases, D1 SQL Runner Console, R2 Storage, R2 Object File Manager, Analytics, Zero Trust, Members & RBAC, Billing & Invoices, API Tokens, Audit Logs, Settings, UI Kit Showcase, Auth (Login, Register, 2FA, Forgot Password), and Error Screens (404, 520, Maintenance).
  • Authentic 68-Token Design System: 1:1 extraction of Cloudflare's production CSS variables, OKLCH color spaces, ring shadows, and typography.
  • 244-Symbol SVG Icon Spritesheet: Includes the official vector Cloudflare icon set extracted from production.
  • Live Theme Customizer: Instant Dark/Light mode toggle, 5 brand accent color swatches (Orange, Blue, Emerald, Purple, Red), and Collapsed Mini-Sidebar mode.
  • ⌘K Spotlight Command Palette: Global quick-switcher with real-time fuzzy filtering across all 22 resources.
  • 100% Zero Runtime Dependencies: No Node.js build step required, no React, no Vue, no Tailwind CLI — just open index.html in any browser or web server.

Customizing Accent Colors

You can switch between brand accent colors dynamically using the live customizer gear, or set the default accent on the <html> element using the data-accent attribute:

<!-- Default Cloudflare Orange --> <html lang="en" data-accent="orange"> <!-- Deep Enterprise Blue --> <html lang="en" data-accent="blue"> <!-- Emerald Green --> <html lang="en" data-accent="emerald"> <!-- Royal Purple --> <html lang="en" data-accent="purple"> <!-- Ruby Red --> <html lang="en" data-accent="red">
